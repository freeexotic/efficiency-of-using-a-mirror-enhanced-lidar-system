# Исследование эффективности использования зеркально-усиленной лидарной системы для нейросетевой сегментации и классификации объектов

Репозиторий со статьёй. Оформление — LaTeX-шаблон статьи НИТУ «МИСиС»
(`misisarticle.cls`, XeLaTeX, две колонки).

## Авторы

- **Федулов Платон** — кафедра инженерной кибернетики НИТУ «МИСиС», Москва, Россия
- **Силаев Всеволод** — кафедра инженерной кибернетики НИТУ «МИСиС», Москва, Россия

## Структура репозитория

- `article.tex` — главный (и единственный) файл статьи: титул, аннотация,
  ключевые слова, все разделы и список литературы (`thebibliography`).
- `misisarticle.cls` — класс оформления (не редактировать).
- `figures/` — рисунки статьи.
- `example/` — эталонная статья для проверки класса, в архив для Overleaf
  не входит.
- `Makefile` — локальная сборка PDF.

## Сборка PDF

Компилятор: **XeLaTeX** (локально подойдёт и tectonic).

```bash
make article
# PDF: build/article.pdf

# либо напрямую:
tectonic article.tex
xelatex article.tex && xelatex article.tex
```

Для Overleaf:

```bash
make dist
# → dist/misis-article.zip
```

New Project → Upload Project → `dist/misis-article.zip`, затем
Menu → Compiler → **XeLaTeX**. Главный файл — `article.tex`.
В архив нужно добавить папку `figures/`, если загружаете проект вручную.

## Происхождение текста

Текст статьи перенесён из черновика статьи ГрафиКон-2026
(шаблон `ceurart`): разделы «Введение», «Постановка задачи», «Методы и
алгоритмы», «Результаты экспериментов», «Обсуждение результатов»,
«Выводы и заключение» и список литературы. Список литературы набран
вручную в `thebibliography` в порядке первых ссылок.
